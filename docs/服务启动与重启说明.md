# FastBug Collector 服务启动与重启说明

本文说明 Windows 上 FastBug 本地 Collector 的启动、验证与重启方法。Collector 用 USB ADB 与安卓平板上的 Capture Agent 通信，并在本机生成证据包。

## 当前测试设备的启动参数

当前已连接的测试平板与 Agent 使用以下参数：

```powershell
$serial = 'JYTC656A251222000569'
$package = 'com.fastbug.captureagent'
$session = '2b37ddde-9eeb-4f9c-b325-bf08c6cebbba'
```

Collector 默认监听本机 `127.0.0.1:52741`。脚本启动时会自动建立 `adb reverse tcp:52741 tcp:52741`，因此平板端应使用 `http://127.0.0.1:52741` 访问 Collector。

## 启动前检查

在项目根目录 `D:\project\fastbug` 打开 PowerShell，先确认设备已通过 USB 连接并被 ADB 识别：

```powershell
adb devices
adb -s JYTC656A251222000569 get-state
```

第二条命令应输出 `device`。

Collector 还要求当前 Windows 用户已配置以下环境变量；它们包含云效和对象存储凭据，**不要写入项目文件或提交到 Git**：

```text
YUNXIAO_TOKEN
FASTBUG_OSS_ENDPOINT
FASTBUG_OSS_ACCESS_KEY_ID
FASTBUG_OSS_ACCESS_KEY_SECRET
```

可仅检查变量是否存在（不会显示变量值）：

```powershell
'YUNXIAO_TOKEN','FASTBUG_OSS_ENDPOINT','FASTBUG_OSS_ACCESS_KEY_ID','FASTBUG_OSS_ACCESS_KEY_SECRET' |
  ForEach-Object { "$_ : " + [bool][Environment]::GetEnvironmentVariable($_, 'User') }
```

## 启动服务

在项目根目录运行：

```powershell
.\collector\start.ps1 `
  -Serial JYTC656A251222000569 `
  -Package com.fastbug.captureagent `
  -Session 2b37ddde-9eeb-4f9c-b325-bf08c6cebbba
```

成功后会显示类似内容：

```text
Collector ready on http://127.0.0.1:52741
Serial: JYTC656A251222000569
Session ID: <会话 ID>
```

启动窗口需要保持打开。若省略 `-Session`，服务会生成新的会话 ID；此时必须重新把该 ID 写入/传给平板 Agent，二者才能互通。

## 配置或重新打开平板 Agent

使用启动输出中的会话 ID 执行下面的命令，打开并配置平板端 Agent：

```powershell
adb -s JYTC656A251222000569 shell am start -n com.fastbug.captureagent/.MainActivity --es collector_url http://127.0.0.1:52741 --es session_id 2b37ddde-9eeb-4f9c-b325-bf08c6cebbba
```

随后在平板端授予录屏和悬浮窗权限，并点击“开始采集”。

## 验证服务

本机健康检查：

```powershell
Invoke-RestMethod http://127.0.0.1:52741/health
```

正常结果含有 `ok: True` 和当前 `sessionId`。也可在浏览器打开 `http://127.0.0.1:52741/` 查看采集页面。

检查 ADB 反向映射：

```powershell
adb -s JYTC656A251222000569 reverse --list
```

应包含 `tcp:52741 tcp:52741`。

## 重启服务

1. 在正在运行 Collector 的 PowerShell 窗口按 `Ctrl+C`，等待进程退出。
2. 重新执行“启动服务”中的命令，并继续使用相同的 `-Session`，这样平板 Agent 无须重新配置。
3. 执行健康检查确认已恢复。

如果原终端已关闭但端口仍被占用，可先定位并停止该端口对应的进程：

```powershell
$collectorPid = (Get-NetTCPConnection -LocalPort 52741 -State Listen).OwningProcess
Stop-Process -Id $collectorPid
```

然后再次执行启动命令。请只停止 `52741` 监听进程，避免误结束其他 Node 服务。

## 证据与日志位置

- 采集证据包：`D:\project\collector-data\captures\<capture_id>\`
- 启动日志：`D:\project\collector-data\collector-*.stdout.log` 与 `collector-*.stderr.log`（如由后台启动脚本生成）
- Collector 服务实时日志：启动 Collector 的 PowerShell 窗口

## 常见问题

| 现象 | 排查方式 |
| --- | --- |
| `get-state` 不是 `device` | 检查 USB 连接、平板 USB 调试授权，然后执行 `adb devices`。 |
| 提示缺少环境变量 | 在 Windows“用户环境变量”配置所需变量后，关闭并重新打开 PowerShell。 |
| 端口 `52741` 已被占用 | 按“重启服务”定位并停止旧的监听进程。 |
| 平板无法连接 Collector | 确认 Collector 正在运行，并确认 `adb reverse --list` 中有 `tcp:52741 tcp:52741`。 |
| 请求提示 Session ID 不匹配 | 用 Collector 启动输出的会话 ID 重新执行“配置或重新打开平板 Agent”命令。 |
